# Introducción a Resigard

Resigard es una aplicación móvil para la gestión de espacios residenciales.\
Permite a **administradores, propietarios y personal de seguridad** operar desde una misma plataforma.

### Roles disponibles

* **Administrador**: acceso total a módulos y configuraciones.
* **Propietario**: gestiona su propiedad y puede crear accesos, pagos y reservas.
* **Seguridad**: controla accesos y registra entradas/salidas.

### Acceso a la app

1. Descarga la app desde App Store o Google Play.
2. Inicia sesión con tu correo y contraseña.
3. Si olvidaste tu contraseña, usa la opción **Recuperar contraseña**.
