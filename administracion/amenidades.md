# Amenidades

## Crear una amenidad

1. Entra a **Administración > Amenidades > Amenidades**.
2. Presiona **Agregar**.
3. Captura los datos básicos:
   * **Nombre de la amenidad**: nombre visible para administración y residentes.
   * **Descripción de la amenidad**: información general, condiciones de uso o detalles relevantes.
   * **Amenidad habilitada**: activa esta opción para permitir que la amenidad esté disponible.
   * **Reglamento**: adjunta un archivo o imagen con el reglamento, si aplica.
4. Presiona **Agregar**.
5. Si la amenidad se guarda correctamente, la pantalla abrirá la edición para configurar horarios y multimedia.

## Editar una amenidad

1. Entra a **Administración > Amenidades > Amenidades**.
2. Selecciona la amenidad que quieres modificar.
3. Ajusta el nombre, descripción, disponibilidad o reglamento.
4. Presiona **Guardar**.

Si desactivas **Amenidad habilitada**, la amenidad queda deshabilitada para reservas.

## Configurar multimedia

1. Desde **Editar amenidad**, ve a la sección **Multimedia**.
2. Presiona **Editar multimedia**.
3. Configura las imágenes:
   * **Encabezado**: imagen principal que se muestra como portada de la amenidad.
   * **Amenidad**: imágenes ilustrativas adicionales. La cantidad permitida depende del plan contratado.
4. Para agregar una imagen, presiona **Agregar** y selecciona el archivo.
5. Para cambiar el encabezado, toca la imagen actual y elige **Reemplazar**.
6. Para eliminar una imagen, toca la imagen y confirma la eliminación.

## Configurar horarios

1. Desde **Editar amenidad**, ve a la sección **Horarios**.
2. Presiona **Agregar horario** para crear un nuevo horario.
3. Configura los campos del horario:
   * **Disponible**: indica si este horario puede reservarse.
   * **Modo de reserva**: define cómo se puede reservar el horario:
     * **Dentro del horario**: permite reservar un periodo de tiempo dentro del horario configurado, o reservar todo el horario, siempre que se cumplan las demás condiciones.
     * **Todo el horario**: obliga a reservar el horario completo. No permite elegir periodos parciales dentro del horario.
   * **Días de la semana**: selecciona los días en los que aplica el horario.
   * **Desde las / Hasta las**: define el rango de horas disponible.
   * **Cuota por**: indica si la cuota se calcula por hora, evento u otra opción disponible.
   * **Cuota**: monto que se cobrará por la reservación.
   * **Límite de horas**: máximo de horas que una propiedad puede reservar.
   * **Límite de personas**: máximo de personas permitidas en la reservación.
   * **Reservaciones concurrentes**: número de reservaciones que pueden existir al mismo tiempo en ese horario.
   * **Priorizar amenidad**: selecciona otra amenidad para darle prioridad cuando haya conflicto de disponibilidad. Usa **Ninguna** si no aplica.
4. Presiona **Guardar horario**.

Si el horario no está disponible, se muestra como no disponible para reservas aunque la amenidad esté habilitada.

## Duplicar o borrar horarios

1. En **Editar amenidad**, busca el horario correspondiente.
2. Para duplicarlo, presiona el botón de copiar y confirma con **Sí, duplicar**.
3. Para eliminarlo, presiona el botón de borrar y confirma con **Sí, borrar**.

Duplicar un horario es útil cuando necesitas crear varios horarios similares con pequeños ajustes.

## Aprobar o rechazar reservaciones

1. Entra a **Administración > Amenidades > Reservaciones**.
2. Selecciona una reservación de la lista.
3. Elige una acción:
   * **Aprobar**: confirma la reservación y crea una orden de pago para el residente por la cuota correspondiente.
   * **Rechazar**: rechaza la solicitud de reservación.
4. Si la acción se completa correctamente, aparecerá el mensaje **Reservación actualizada**.

Las reservaciones canceladas no pueden cambiarse. Si una reservación ya está en el estado seleccionado, el sistema mostrará un aviso.

## Recomendaciones

* Crea primero la amenidad y después configura sus horarios.
* Mantén deshabilitados los horarios nuevos hasta validar días, horas, cuotas y límites.
* Usa horarios separados cuando la cuota, capacidad o disponibilidad cambie por día o rango de hora.
* Revisa la cuota antes de aprobar una reservación, porque al aprobarla se crea una orden de pago para el residente.
* Usa imágenes claras y actuales para que los residentes identifiquen fácilmente la amenidad.
